# Database Design, Management and Administration

> Database Design, Management and Administration lab exercises using Oracle Database.

---

## Overview

This repository contains practical exercises for the course **Database Design, Management and Administration (MSIS4013.Q22.CTTT)** at University of Information Technology (UIT).

This course is an advanced database course after **Database Systems Fundamentals**, focusing on database management, administration, and programming with Oracle Database instead of SQL Server Management Studio.

What this Lab helps with:
- Managing Oracle Database users, roles, and privileges
- Writing SQL queries and working with database objects
- Practicing PL/SQL programming
- Creating procedures, functions, triggers, and exception handling

What technologies are used:
- <img src="https://img.icons8.com/color/48/oracle-logo.png" width="20"/> Oracle Database
- Oracle SQL Developer
- SQL / PL-SQL
- .docx documentation

## Lab Contents

| Lab | Topics |
|---|---|
| **Lab 1: Oracle Database Administration** | Installing Oracle Database environment<br>Creating users and roles<br>Managing privileges and access control |
| **Lab 2: SQL Language** | Writing SQL queries<br>Views, functions, joins, and subqueries |
| **Lab 3: PL/SQL Fundamentals** | PL/SQL blocks<br>Variables, sequences, cursors, and control structures |
| **Lab 4: Procedures, Functions and Triggers** | Stored procedures and functions<br>Database triggers and data integrity |
| **Lab 5: Advanced PL/SQL** | Exception handling<br>Transactions<br>Advanced procedures, functions, and triggers |
